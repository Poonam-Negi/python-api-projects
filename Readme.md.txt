# Python API Projects – AI/ML Internship Tasks

This repository contains Python projects completed as part of my AI/ML Internship training. These tasks helped me learn and practice working with REST APIs, JSON data, Python programming, Pandas, data analysis, and CSV file handling.

## Projects

### Task 1: Weather Data Analysis

**API Used:** Open-Meteo API

**Features:**

* Fetches weather data for multiple cities
* Extracts temperature, humidity, and wind speed
* Stores data in a Pandas DataFrame
* Saves results to a CSV file
* Identifies:

  * Hottest City
  * Average Temperature
  * Highest Humidity

**Files:**

* `weather_analysis.py`
* `weather_data.csv`

---

### Task 2: User Directory Generator

**API Used:** JSONPlaceholder Users API

**Features:**

* Fetches user data from an API
* Extracts:

  * Name
  * Email
  * Phone
  * Company Name
  * City
* Stores data in a Pandas DataFrame
* Saves results to a CSV file
* Supports:

  * Search User by Name
  * Search Users by Company

**Files:**

* `user_directory.py`
* `users.csv`

---

### Task 3: E-Commerce Product Analysis

**API Used:** Fake Store API

**Features:**

* Fetches product data from an API
* Calculates:

  * Total Products
  * Average Product Price
  * Most Expensive Product
  * Cheapest Product
  * Category-wise Product Count
* Displays results in a clean format

**Files:**

* `product_analysis.py`
